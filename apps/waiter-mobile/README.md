# Restaurant Mesero

Aplicación Flutter para vincular un teléfono con Restaurant Core y operar mesas y pedidos como mesero.

```powershell
cd apps\waiter-mobile
flutter pub get
flutter devices
flutter run -d <device-id>
```

El teléfono debe alcanzar Restaurant Core por la red local. Consulta `docs/waiter-app.md` para configurar Core, vincular el dispositivo, generar el APK y revisar el modelo de seguridad.
